# Мир обуви

Учебный проект по ПМ.02 (УП): приложение для заказа обуви на платформе **1С:Предприятие 8.3** (управляемые формы, файловая информационная база).

Торговая компания «Мир обуви» продаёт обувь через сеть магазинов. Клиент выбирает модель и размер в каталоге и оформляет заказ на одну или несколько пар. Взаиморасчёты ведутся в рублях.

## Цель работы

Разработать приложение для заказа обуви: каталог с изображениями и актуальными остатками, оформление заказов, управление заказами, разграничение прав для четырёх видов пользователей.

## Возможности

- Каталог товаров с фото, ценой за 1 пару и актуальным остатком.
- Поиск по названию, фильтр по категории, сортировка (по названию, по цене, по производителю).
- Описание выбранной модели: состав, описание, доступные размеры с остатком.
- Заказ прямо из каталога: выбор размера из доступных, ввод количества, подтверждение со стоимостью (`N пар × цена = сумма`).
- Автоматическое списание остатков при проведении заказа, контроль «недостаточно товара».
- Текстовая выписка по заказу, сохраняется в папку `Документы\Мир обуви - заказы`.
- Список заказов (дата, клиент, сумма), состав заказа, создание и удаление заказов.
- Список товаров с общей стоимостью склада, количеством проданного и статусом «Продан / Не продан».
- Загрузка данных из Excel одной кнопкой: тип файла определяется автоматически по заголовкам.

## Роли и права

Вход выполняется по логину из справочника пользователей, **пароль не требуется**. Каждому пользователю соответствует пользователь информационной базы и роль конфигурации.

| Возможность | Гость | Авторизованный пользователь | Менеджер | Администратор |

| Просмотр каталога | да | да | да | да |
| Фильтр, поиск, сортировка | нет | да | да | да |
| Оформление заказа | нет | да | да | да |
| Просмотр заказов и их состава | нет | нет | да | да |

## Структура конфигурации

| Объект | Назначение |
|---|---|
| Справочники `Категории`, `Подкатегории`, `Производители`, `Размеры` | классификаторы товаров |
| Справочник `Товары` | модель: категория, подкатегория, производитель, состав, описание, цена, изображение |
| Справочник `Пользователи` | фамилия, имя, отчество, логин, роль |
| Документ `Заказ` | дата, клиент, товары (товар, размер, количество, цена, сумма), итоговая сумма |
| Документ `ПоступлениеТоваров` | приход товара на склад (в том числе начальные остатки) |
| Регистр накопления `ОстаткиТоваров` | остатки по сочетанию «товар + размер» (товарная позиция) |
| Обработка `ГлавноеМеню` | стартовая форма |
| Обработка `Каталог` | каталог товаров и оформление заказа |
| Обработка `ЗагрузкаДанных` | загрузка и очистка данных |
| Общие модули `РаботаСПользователем`, `РаботаСТоварами` | роль текущего пользователя, доступные размеры и цена |
| Роли `Администратор`, `Менеджер`, `АвторизованныйПользователь`, `Гость` | права доступа |

## Запуск

### Вариант 1. Из выгрузки информационной базы (быстрее всего)

1. Установите платформу 1С:Предприятие 8.3.
2. Создайте пустую информационную базу (без конфигурации).
3. Конфигуратор → «Администрирование» → «Загрузить информационную базу…» → файл `db/1Cv8.dt`.
4. Запустите «1С:Предприятие» и войдите под любым логином из таблицы выше (пароль не нужен).

### Вариант 2. Из файлов конфигурации и Excel

1. Создайте пустую информационную базу.
2. Конфигуратор → «Конфигурация» → «Загрузить конфигурацию из файлов…» → папка `src`.
3. Обновите конфигурацию базы данных (**F5**, ответ «Да»).
4. Загрузите данные из папки `data` (см. ниже).

## Загрузка данных

Главное меню → **Загрузка данных** → **Загрузить файл…**. Файлы выбираются по одному или сразу все. Порядок загрузки:

1. `Sizes_import.xlsx`: размеры (35)
2. `Users_import.xlsx`: пользователи (20) и пользователь `guest`
3. `Products_import.xlsx`: товары (31)
4. `Stock_Items_import.xlsx`: остатки (92 строки)
5. `Orders_import.xlsx`: заказы (10)

Остатки и заказы требуют, чтобы товары, размеры и пользователи уже были загружены. Заказы при повторной загрузке пропускаются, если они уже есть. Изображения товаров добавляются вручную.

Кнопка **Очистить все данные** удаляет загруженные справочники и документы, чтобы можно было загрузить данные заново.

2. «Администрирование» → «Выгрузить информационную базу…» → `db/1Cv8.dt`.
3. В корне репозитория выполнить:

```

git commit -m "Описание изменений"
git push
```
